# Lingtype

用英文打字練習單字與短文，並查看繁體中文、日文或韓文翻譯。

## 本機執行

需要 Python 3.10 以上。在專案資料夾執行（若系統預設版本較舊，請將 `python3` 換成 `python3.12` 等已安裝的版本）：

```sh
python3 -m pip install --target .deps -r requirements.txt
python3 server.py
```

開啟 http://localhost:8765 。

頁首可切換「書庫」、「我的書櫃」、「單字本」和「紀錄」；閱讀途中切到其他頁面會自動暫停，回到書櫃按「繼續閱讀」可接著讀。右上角的語言（繁體中文、日本語、한국어）同時決定介面文字與翻譯語言，選擇會保存在瀏覽器；第一次開啟時依瀏覽器語言預設。

點選文章或直接按任意鍵即可開始打字；打字時周圍介面會變淡（專注模式）。文章依序顯示目前的句子和翻譯，打完這次選定的文章或段落後顯示結果，可查看成績及標記單字，再選擇下一段或重新練習。隨時按 Esc 或「結束」也能查看結果和標記單字，未完成的進度會保留；按 Enter 從停下的地方繼續，Shift+Enter 重新開始。計時只算打字的時間：離開文章或超過 6 秒沒有打字時暫停，下一個按鍵再繼續。句號後面的空白要自己打，段落之間按一次空白或 Enter 即可，漏打空白會算一次錯字。單字會連續顯示，可在單字之間按空白鍵；文章練習可用 Backspace 修改輸入。

首頁是「書庫」：伺服器隨附的小說與論文，加上大家分享的書，可依分類、關鍵字與熱門程度挑選。在書本頁按「加入書櫃」後，書會放進「我的書櫃」，之後隨時從書櫃拿出來讀。內建的短文也在書櫃裡。

每本書有自己的書本頁，顯示已讀的段落比例、接著要讀的位置，以及依章節列出每一段開頭的目錄。點目錄中的任一段，就從那一段開始打字，一直讀到該章節結束；接著按 Enter 讀下一章，讀完整本書後回到書本頁。「繼續閱讀」會先回到還沒打完的段落並保留已打的內容，沒有未完成的段落時則從下一個未讀段落開始。打過的段落會標成已讀，書籤和已讀段落保存在這個瀏覽器，也包含在資料備份中。閱讀畫面上方顯示書名、章節和目前是第幾段，「目錄」可回到書本頁。沒有分段的短文會以句子當作段落。匯入教材後也會先開啟它的書本頁。

練習畫面「更多」中的「編輯並另存教材」可以修正文字並建立獨立副本；原教材、練習進度及公開分享都會保留。新副本是純文字，不包含原章節、譯文、圖表或 PDF 頁面；長文會重新分段，公式會轉成需要輸入的 TeX 文字。副本保留可用的出處並標示為編輯版，若要公開需重新分享。

匯入後會依目前選擇的語言在背景分批預先翻譯全文，包括長文章的其他章節；超過 100,000 字元的書（例如整本小說）只預先翻譯第一個章節，其餘段落在閱讀時才翻譯。畫面會顯示準備進度；部分句子失敗時可重試，已成功的句子不會重複翻譯。已翻譯的句子會保存在這個瀏覽器，重複匯入或練習時會重用；翻譯尚未完成時仍可開始練習。

## 隨附書庫

`library/` 中的練習冊會在伺服器啟動時放上書庫：Project Gutenberg 的公版小說（《愛麗絲夢遊仙境》、《福爾摩斯冒險史》、《時光機器》、《彼得潘》、《綠野仙蹤》、《格林童話》），以及採用 CC BY 4.0 授權的 arXiv 論文（Chain-of-Thought、Mistral 7B、LLaMA、DPO、Constitutional AI）。每本書在所有伺服器上的 ID 都相同，且沒有下架碼，只能由管理者用 `moderate.py remove-book` 移除；移除後重新啟動也不會再放回。檔案內容更新後，下次啟動會取代舊文字，保留按讚、留言與排行。隨附書計入公開內容配額（約 5 MB）。設定 `LINGTYPE_LIBRARY_DIR` 可改用其他資料夾，設為空字串則不放隨附書。

要重新下載或增減書目，請編輯 `build_library.py` 後執行 `PYTHONPATH=.deps python3 build_library.py`（可在後面加書名代號只重建部分書）。小說依章節切分，超過 12,000 字元的章節會在段落之間分成數部分；論文只收 CC BY 或 CC0 授權者，腳本會先檢查 arXiv 頁面上的授權。

## 測試

```sh
node --test test/*.test.mjs
PYTHONPATH=.deps python3 -m unittest discover -s test -p 'test_*.py'
```

啟動 `python3 server.py` 後，可用 Node.js 22 以上執行 `node test/browser-e2e.mjs`，在 Chrome 或 Chromium 實際操作完整流程（打字、結果、紀錄、切換語言、匯入、手機版），截圖存到 `.taste-skill/e2e/`。測試使用獨立的暫存瀏覽器資料，不會修改個人的瀏覽器資料；若瀏覽器不在一般安裝位置，請以 `CHROME_PATH` 指定執行檔路徑。可用 `LINGTYPE_URL` 指定測試伺服器網址；若不測試需要網路的 YouTube 匯入，設定 `LINGTYPE_SKIP_NETWORK=1`。`node test/bookshelf-browser.mjs` 會走一次書庫、加入書櫃、從指定段落開始讀和繼續閱讀的流程，需要伺服器載入隨附書庫。

`node test/pdf-offline-browser.mjs` 會阻擋外部 HTTPS，檢查專案內的 PDF.js 能否繪製原頁。隨附程式庫及字型的來源與授權見 `site/vendor/pdfjs/README.md`。導覽與按鈕的動態圖示來自 PulsoIcon（ISC），由 Motion（MIT）播放，滑過或聚焦時才會動，系統要求減少動態時保持靜止；兩者都放在 `site/vendor/` 中，來源與授權見各自的 README。

「我的書櫃」的「加入自己的書」會開啟匯入頁，有三種方式，匯入後開啟書本頁：

- **網址**：YouTube 影片（取英文字幕，有人工字幕時優先使用；影片若有人工的繁中、日文或韓文字幕，會直接當作逐句翻譯，不用翻譯服務）、一般網頁文章（只取文章本文，略過選單、引用標記與「參考資料」之後的內容）或 arXiv 論文（保留章節）。伺服器不會讀取本機或內部網路的網址。
- **檔案**：拖曳或選擇 PDF、Word（DOCX）、EPUB、TXT、Markdown、HTML、SRT / VTT 字幕或 Lingtype 練習冊，20 MB 以內。PDF 最多 2,000 頁，超過時請先拆分；每頁會成為章節，較長的頁面會分成數段。練習時旁邊會顯示原頁，PDF.js 已隨專案提供；掃描成圖片的 PDF 沒有文字可取。arXiv 網址（abs、html、pdf）會匯入 HTML 版，附圖表與公式，公式只顯示、不用打。
- **貼上文字**。

超過約 12,000 字元的內容會自動分成數個部分（EPUB 依章節），一次練習一部分，打完後可在結果頁選擇下一部分。彎引號、長破折號、刪節號等鍵盤打不出的符號會換成一般鍵盤符號。匯入內容與選取的單字儲存在目前的瀏覽器；影片本身不會播放。

PDF 擷取時，只有能確認為 PDF 明確標記的非正文內容才會略過；沒有標記的頁首或頁碼可能保留，以免誤刪重複正文或數字。標記結構不明時也會保留原文。跨行連字號也會保留：若它只是排版時加入的斷字，匯入文字可能需要自行留意。

EPUB 依書中的閱讀順序匯入章節，保留短篇章與短段落，並略過明確標記為導覽或封面的頁面。若閱讀順序指向的章節檔案遺失或路徑無效，會顯示錯誤，避免匯入不完整內容。

匯入後可從每批最多 20 個候選字中選擇要練習的單字，也可以搜尋文章中的其他字、切換批次或標記已認識的字。候選清單依文章順序排列，只排除一小部分常見功能字，並非精確的單字難度判定，請自行挑選。論文可先選章節，讓候選字集中在該章節。

練習時可查看時間、WPM、正確率和進度；單字模式顯示錯誤次數。WPM 使用正確字元數除以五，再除以經過分鐘數；句間的空白算一個字元，段落換行不另外計入。文章正確率依目前輸入計算，修正錯字後會更新。練習可暫停，未完成進度會保存在目前的瀏覽器，重新開啟時可繼續；修改選字會清除該教材的單字練習進度，並先提示確認。文章完成後，可點選原文中的單字加入或移出單字本，或框選一段後按浮出的按鈕一次加入。新加入且尚未選入教材的字也會加入教材選字；從單字本移除時會保留教材選字。打錯的字也會列出，也可重練打錯的單字、練習下一段，並查看同一教材及段落的最近成績與個人最佳 WPM。最近十次結果保存在目前的瀏覽器；匯入教材可從練習區刪除。

練習區的「匯出練習冊」會下載包含文章、已準備的逐句翻譯、章節與單字的 JSON 檔案，別人可在「匯入教材」開啟，也可用來備份個別教材。單一練習冊上限為 2 MB；分享前請確認有權使用文章。

「紀錄」頁的「資料備份」可匯出並還原這個瀏覽器的 Lingtype 資料，包含教材、PDF 原檔、翻譯、單字本、練習進度、成績、公開教材的下架碼、社群讀者身分及未確認送出的留言內容。備份上限為 200 MB；若 PDF 原檔遺失或備份超過上限，匯出會顯示失敗，不會產生不完整的備份。新備份對每個 PDF 記錄 SHA-256，還原前會檢查內容是否變更；此檢查不能防止有人同時竄改檔案和校驗值。PDF 校驗需要瀏覽器 Web Crypto，通常必須使用 HTTPS 或 localhost。備份含有下架碼與社群讀者身分，請妥善保存；還原會取代目前的 Lingtype 資料，並重新載入頁面。還原功能需要瀏覽器支援 IndexedDB。舊版備份若不包含 PDF，還原時不會刪除原有的 PDF；含 PDF 但沒有校驗值的舊備份無法檢查完整性，若同教材已有不同原檔則不會還原。舊版備份沒有讀者身分或未確認留言時，也會保留還原所在瀏覽器的資料。

為避免資料被不同分頁互相覆寫，支援 Web Locks 的瀏覽器一次只能開啟一個 Lingtype 編輯分頁。若瀏覽器或網站連線環境不支援 Web Locks，畫面會提示只開啟一個分頁。

書庫右上角的「上傳書本」會開啟上傳視窗：可直接拖曳檔案上傳（格式與匯入頁相同，上傳的書也會放進自己的書櫃），或從自己的書櫃挑選一本；書本頁的「分享到書庫」和閱讀畫面「更多」中的「公開分享」也會開啟同一個視窗並選好那本書（不支援對話框的瀏覽器會改為確認後直接分享）。可選擇小說、論文、網路文章或文件等分類（預設依來源判斷）、加上封面，並需勾選確認有權公開。上傳完成後會直接開啟該書在書庫的頁面。從書庫加入的書已經公開，不會再出現在可分享的清單中。「公開分享」會把練習冊發布到這個伺服器的公開清單，其他能連到該伺服器的使用者可瀏覽及加入教材。發布者可在同一瀏覽器下架；下架權限保存在該瀏覽器，清除瀏覽器資料後無法自動找回。公開資料庫位於 `.lingtype/public.db`，部署時需保留並備份該目錄。本機預設只監聽 `127.0.0.1:8765`，因此本機連結不能讓網路上的其他人開啟；要提供網路公開服務仍需部署有持久儲存的伺服器。可用 `LINGTYPE_HOST`、`LINGTYPE_PORT`、`LINGTYPE_DATA_DIR` 設定監聽與資料位置。

伺服器管理者可在有資料目錄存取權的機器上，使用 `python3 moderate.py show-book 文章ID` 查看教材，或用 `python3 moderate.py list-comments 文章ID` 找出留言 ID，再以 `python3 moderate.py show-comment 留言ID` 查看。要移除時使用 `remove-book 文章ID` 或 `remove-comment 留言ID`；命令會先顯示內容，並要求輸入完整 ID 才執行。移除文章也會刪除其封面、留言和互動紀錄。伺服器保留少量已移除文章或留言的 ID，以防延遲的重送讓內容重新出現；這些 ID 計入內容配額，不包含原文或留言內容。若未設定 `LINGTYPE_DATA_DIR`，可在動作前加 `--data-dir /資料目錄` 指向部署時使用的目錄。這些操作直接存取本機資料庫，請限制該目錄的作業系統存取權，並在操作前備份。

分享前會先在瀏覽器保存下架碼；若連線中斷而無法確認分享結果，畫面會顯示教材 ID。可到書庫確認是否已發布；若要下架，可在「用下架碼下架」輸入該 ID，讓系統使用此瀏覽器已保存的下架碼。如果瀏覽器無法保存下架碼，系統不會發布。

每次分享都是獨立的公開快照，不會改變原教材的進度或公開來源。若發布者也想讓自己的練習計入該分享，請從書庫開啟它並選擇「加入書櫃」；同一分享會重用既有副本，不同分享的進度分開保存。教材選單會以公開 ID 的前八碼標示這些副本。

封面更新使用伺服器版本檢查，避免逾時的舊上傳覆蓋後來的封面；不同分頁同時更新時，衝突的上傳會重新讀取版本再試。某篇教材首次用新版頁面更新封面後，仍開著的舊版頁面必須重新整理才能再更新該教材的封面；尚未用新版更新的教材仍可由舊版頁面管理。

公開教材的閱讀、開始與完成紀錄若暫時無法送出，會保存在目前瀏覽器並於恢復連線後重試；同一讀者重送閱讀或開始紀錄不會重複計數。若瀏覽器儲存失敗，畫面會提示，本次工作階段仍會嘗試送出，但關閉頁面後未送出的紀錄可能遺失。

留言送出後若無法確認結果，可在該教材的留言區選取尚未確認的留言、檢查內容並手動重試；系統會沿用原識別，避免重複發表。不同的未確認留言都會保留，已確認或已被移除的留言會從待確認清單移除。也可選擇不再追蹤，這只移除本機紀錄，不會刪除可能已發表的留言；之後重送相同內容可能重複發表。

教材與逐句翻譯會從原有的 localStorage 複製至 IndexedDB，原資料保留；其他練習資料仍存在 localStorage。瀏覽器儲存失敗時畫面會顯示提示，請在重新整理前匯出需要保留的練習冊。公開內容配額為 100 MB，包含教材、封面、留言、成績和互動紀錄；SQLite 的索引與檔案空間不計入配額，因此實際資料庫檔案可能較大。每個連線來源每分鐘最多 120 次 API 請求；反向代理後方會以代理的連線位址計算，部署時應另依實際架構設定流量限制。一般網頁匯入會直接連線至驗證過的公開 IP，不使用系統 HTTP proxy；只能透過 proxy 對外連線的環境需要額外設定網路出口。

伺服器預設最多同時處理 64 個連線，其中超過 2 MB 的檔案匯入最多同時處理 4 個；超過上限時回傳 503。閒置連線、完整 HTTP 標頭及整次連線的期限分別為 15、30、300 秒，可依上傳速度及部署環境調整 `LINGTYPE_MAX_CONNECTIONS`、`LINGTYPE_MAX_LARGE_UPLOADS`、`LINGTYPE_IDLE_TIMEOUT`、`LINGTYPE_HEADER_TIMEOUT`、`LINGTYPE_REQUEST_TIMEOUT`（後三者單位為秒，均須大於零）。例如慢速連線匯入 20 MB 檔案需要更長時間時，應提高整次連線期限；期限到了會關閉連線，已開始的伺服器工作仍須等自身完成或逾時才會釋放名額。反向代理也應設定相容的逾時及連線上限。

匯入內容可使用非官方 `googletrans` 套件逐句翻譯，不需要 API 金鑰；Google 無法使用時改用免費的 MyMemory 翻譯（每天約 5000 字元，單字譯文品質可能較差）。翻譯在背景準備，不會擋住練習。譯文依句子與語言儲存在瀏覽器中以減少重複請求。文章和選取的單字會傳送至翻譯服務。此套件依賴 Google 翻譯網頁服務，服務變動或請求限制可能導致翻譯失敗；Google 限制請求時套件會原封不動傳回英文，伺服器會把這種情況視為失敗，網頁顯示「尚無此語言的翻譯」並可繼續練習，不會把英文當成譯文保存。

## 單字本

在練習結果點文章裡的單字、框選一段，或在「挑選單字」勾選，單字就會連同出現的句子（最多三句）和出處收進「單字本」。單字本可以「練習單字」或「練習例句」（例句附翻譯，像文章一樣打）；練習時打錯較多的字會排在前面。單字本也會出現在教材選單裡。資料存在目前的瀏覽器。

單字本的「練習待複習」只練習到期的字，新加入的字會立即列入。練習正確後，下次複習間隔依序為 1、3、7、14、30 天；打錯則改為 1 天。練習文章時，只要單字本中的字出現在已打過的內容，也會更新複習時間。

練習時可按「編輯譯文」修正目前句子或單字的譯文；單字本中也可以編輯單字譯文。句子譯文會隨練習冊匯出，選取的單字譯文也會保留在練習冊中。

單字本會顯示下一次複習時間，並說明文章練習也會更新複習安排。從單字本移除單字時會先確認，只移除該字及其複習紀錄，教材原有的選字會保留；本次操作可按「復原移除」取回。結果頁的文章單字也可以使用鍵盤選取。

結果頁的選取標記代表單字是否在單字本中；教材已選過的字若已從單字本移除，可以直接點一次重新加入。用鍵盤選字時，可用方向鍵在文章中的字之間移動，按空白鍵切換。單字本的每個字會標示「待複習」或下次複習時間；手機練習頁的範圍與來源設定收在可展開的區域。
