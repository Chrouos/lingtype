# Lingtype

用英文打字練習單字與短文，並查看繁體中文、日文或韓文翻譯。

## 本機執行

在專案資料夾執行：

```sh
python -m pip install --target .deps -r requirements.txt
python server.py
```

開啟 http://localhost:8765 。

頁首可切換「練習」、「匯入」、「公開」和「紀錄」；練習途中切到其他頁面會自動暫停，回到練習後可繼續。右上角的語言（繁體中文、日本語、한국어）同時決定介面文字與翻譯語言，選擇會保存在瀏覽器；第一次開啟時依瀏覽器語言預設。

點選文章或直接按任意鍵即可開始打字；打字時周圍介面會變淡（專注模式），只有游標所在的句子是全黑。計時只算打字的時間：離開文章或超過 6 秒沒有打字時暫停，下一個按鍵再繼續。打完一篇會直接接著下一段（沒有下一段時接著下一課）繼續打，中間不出現結果畫面；每篇仍各自記入練習紀錄。隨時按 Esc 或「結束」停止，結果會合計這次連續打過的所有內容，並保留目前位置：按 Enter 從停下的地方繼續，Shift+Enter 重新開始。文章練習像讀書一樣顯示整篇文章，每段英文下方接著該段翻譯；只有正在打的句子是全黑，已打過與還沒打到的文字都會淡化，畫面會跟著游標捲動；句號後面的空白要自己打，段落之間按一次空白或 Enter 即可，漏打空白會算一次錯字。單字會連續顯示，可在單字之間按空白鍵；文章練習可用 Backspace 修改輸入。

## 測試

```sh
node --test test/*.test.mjs
python -m unittest discover -s test -p 'test_*.py'
```

啟動 `python server.py` 後，可用 `node test/browser-e2e.mjs` 在 Chrome 實際操作一次完整流程（打字、結果、紀錄、切換語言、匯入、手機版），截圖存到 `.taste-skill/e2e/`。

「匯入」頁有三種方式，匯入後直接開始邊讀邊打：

- **網址**：YouTube 影片（取英文字幕，有人工字幕時優先使用；影片若有人工的繁中、日文或韓文字幕，會直接當作逐句翻譯，不用翻譯服務）、一般網頁文章（只取文章本文，略過選單、引用標記與「參考資料」之後的內容）或 arXiv 論文（保留章節）。伺服器不會讀取本機或內部網路的網址。
- **檔案**：拖曳或選擇 PDF、Word（DOCX）、EPUB、TXT、Markdown、HTML、SRT / VTT 字幕或 Lingtype 練習冊，20 MB 以內。掃描成圖片的 PDF 沒有文字可取。
- **貼上文字**。

超過約 12,000 字元的內容會自動分成數個部分（EPUB 依章節），一次練習一部分，打完自動接著下一部分。彎引號、長破折號、刪節號等鍵盤打不出的符號會換成一般鍵盤符號。匯入內容與選取的單字儲存在目前的瀏覽器；影片本身不會播放。

匯入後可從每批最多 20 個候選字中選擇要練習的單字，也可以搜尋文章中的其他字、切換批次或標記已認識的字。候選清單依文章順序排列，只排除一小部分常見功能字，並非精確的單字難度判定，請自行挑選。論文可先選章節，讓候選字集中在該章節。

練習時可查看時間、WPM、正確率和進度；單字模式顯示錯誤次數。WPM 使用正確字元數除以五，再除以經過分鐘數；句間的空白算一個字元，段落換行不另外計入。文章正確率依目前輸入計算，修正錯字後會更新。練習可暫停，未完成進度會保存在目前的瀏覽器，重新開啟時可繼續；修改選字會清除該教材的單字練習進度，並先提示確認。文章完成後，可點選原文中的單字加入或移除單字練習，或框選一段後按浮出的按鈕一次加入，打錯的字也會列出，也可重練打錯的單字、練習下一段，並查看同一教材及段落的最近成績與個人最佳 WPM。最近十次結果保存在目前的瀏覽器；匯入教材可從練習區刪除。

練習區的「匯出練習冊」會下載包含文章、翻譯、章節與單字的 JSON 檔案，別人可在「匯入教材」開啟。單一練習冊上限為 2 MB；分享前請確認有權使用文章。

「公開分享」會把練習冊發布到這個伺服器的公開清單，其他能連到該伺服器的使用者可瀏覽及加入教材。發布者可在同一瀏覽器下架；下架權限保存在該瀏覽器，清除瀏覽器資料後無法自動找回。公開資料庫位於 `.lingtype/public.db`，部署時需保留並備份該目錄。本機預設只監聽 `127.0.0.1:8765`，因此本機連結不能讓網路上的其他人開啟；要提供網路公開服務仍需部署有持久儲存的伺服器。可用 `LINGTYPE_HOST`、`LINGTYPE_PORT`、`LINGTYPE_DATA_DIR` 設定監聽與資料位置。

匯入內容可使用非官方 `googletrans` 套件逐句翻譯，不需要 API 金鑰；Google 無法使用時改用免費的 MyMemory 翻譯（每天約 5000 字元，單字譯文品質可能較差）。翻譯在背景準備，不會擋住練習。譯文依句子與語言儲存在瀏覽器中以減少重複請求。文章和選取的單字會傳送至翻譯服務。此套件依賴 Google 翻譯網頁服務，服務變動或請求限制可能導致翻譯失敗；Google 限制請求時套件會原封不動傳回英文，伺服器會把這種情況視為失敗，網頁顯示「尚無此語言的翻譯」並可繼續練習，不會把英文當成譯文保存。

## 單字本

在練習結果點文章裡的單字、框選一段，或在「挑選單字」勾選，單字就會連同出現的句子（最多三句）和出處收進「單字本」。單字本可以「練習單字」或「練習例句」（例句附翻譯，像文章一樣打）；練習時打錯較多的字會排在前面。單字本也會出現在教材選單裡。資料存在目前的瀏覽器。
