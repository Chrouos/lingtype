# 英文打字與語言學習遊戲：第一版設計

## 目標

製作瀏覽器遊戲，讓使用者先練習英文單字，再輸入包含這些單字的英文短文，並參照自己選擇的翻譯學習。第一版優先完成流暢、容易理解的打字體驗。

## 教材與語言

- 練習語言為英文；教材翻譯可切換繁體中文、日文與韓文。操作介面第一版固定使用繁體中文。
- 手動準備少量原創英文範例短文、三種翻譯，以及每篇對應的單字與翻譯；不依賴翻譯 API 即可遊玩。
- 每份教材包含識別碼、標題、來源與授權資訊、英文段落、各語言段落翻譯，以及依序排列的重點單字與各語言翻譯。原創範例標註為原創。
- 教材整理者手動挑選較有學習價值或較不常見的單字，排除 I、am、for 等常見基礎字；第一版不做自動難度判定。文章練習保留完整原文。
- 玩家選擇教材與翻譯語言，再選擇單字或文章模式；單字完成後提供進入同篇文章的操作，也可直接選擇文章模式。

## 單字模式

- 一次顯示一個英文單字與所選語言的翻譯。第一個字元輸入時開始整輪計時。
- 任一字母輸入錯誤時，立即清空目前單字輸入，累計一次錯誤，從該單字第一個字母重新輸入；計時持續。輸入完整正確單字後自動前往下一個。
- 沒有倒數或時間上限。完成後顯示總時間、單字數與錯誤次數，並提供重玩與進入文章練習。

## 文章模式

- 顯示英文段落與完整翻譯，玩家可持續輸入；逐字顯示正確與錯誤狀態，支援 Backspace 修正。
- 首次輸入開始計時；輸入長度達到原文長度時完成。以最終輸入與原文逐字比較，正確率為正確字元數除以原文字元數；已修正錯誤不列入最終錯誤數。
- WPM 以最終正確字元數除以 5，再除以耗時分鐘數計算。結果顯示時間、WPM、正確率及重玩操作。

## 體驗與範圍

- 介面清楚呈現進度、當前輸入與結果，單字錯誤和完成練習時提供簡單視覺回饋。遊戲化獎勵、音效與進階動畫先保留為後續設計，不妨礙核心輸入。
- 不需帳號、後端或雲端儲存；第一版以瀏覽器本地教材運作，重新整理不要求保存進度。
- 使用者上傳與公開分享、外部文章擷取、YouTube 字幕與影片同步跟打、翻譯服務串接均留待後續。
- 教材資料結構保留來源及多語翻譯欄位，未來可擴充上傳、字幕分段與翻譯提供者；第一版不宣稱這些功能已可用。之後選擇免費翻譯服務時再評估額度、使用條款及品質。

## 實作方向

採用輕量前端網頁與本地靜態教材，避免第一版依賴外部服務。具體框架與工具由實作規劃決定。打字邏輯、教材資料與介面分開，方便未來擴充。驗證至少涵蓋單字錯誤重打、文章錯誤及修正、成績計算、語言切換與基本操作。

## 曾考慮的方案

1. 手動整理範例教材：能先驗證學習流程與翻譯品質，教材增加需人工處理。使用者選擇此方案。
2. 初版串接翻譯服務：新增教材較方便，但需要處理免費額度、可用性及翻譯品質；延後處理，保留擴充空間。
